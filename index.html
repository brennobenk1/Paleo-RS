Limitações

A densidade de registros mede esforço de publicação, não riqueza fossilífera. Um município aparecer vazio no mapa quase nunca significa que não há fóssil lá — significa que ninguém publicou. A exceção é geológica: município assentado sobre embasamento cristalino ou rocha vulcânica não terá fóssil nenhum, e isso é fim de linha, não convite. Ler este banco como proxy de potencial fossilífero é o erro mais fácil de cometer com ele.

Esta é a semente do banco: sete registros do Triássico, todos conferidos na publicação original ou em redescrição de acesso aberto. Permiano, Quaternário e a plataforma continental ainda estão vazios — a coluna estratigráfica acima mostra isso de propósito, em vez de esconder os períodos sem dado.

Como citar

Citar este banco não substitui citar a fonte primária de cada registro. O banco é um índice para a literatura, não um substituto dela. Dados sob CC BY 4.0, código sob MIT.
